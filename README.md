<p>
  <strong>Kuljep (Kuliner Jepara)</strong> is a web-based platform designed to introduce and promote culinary destinations in Jepara. Users can explore traditional foods, discover popular restaurants, and get information about local culinary experiences in Jepara through a modern and user-friendly interface.
</p>

<p>
  This project was developed as a learning and portfolio project in web development, focusing on responsive design, user experience, and local culinary promotion.
</p>
